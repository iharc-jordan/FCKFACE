# FCKFACE

**Face Cloaking Kit for Feature Alteration and Cross-model Evaluation**

FCKFACE is a planned photo privacy tool: submit a photo and receive an edited result designed to make facial matching harder across recognition systems. The name is intentionally a joke; the effectiveness claim will need serious evidence.

## Status

This repository is the initial project setup. There is no upload app, deployment, or validated cloaking method yet. Earlier local experiments have **not** demonstrated reliable nonmatching. Do not treat their images as protection against commercial or future recognition systems.

The previous single-user research repository and its private evidence remain on Jordan's computer. [Prior work and handoff](docs/prior-work.md) identifies what was tried and where to find it. Personal photographs, embeddings, model weights, and generated results are excluded from this repository.

Jordan is creating the GitHub Project and Vercel project. Application architecture, inference location, data handling, and a release license have not been chosen. Research is paused after this setup until Jordan directs it to resume.
