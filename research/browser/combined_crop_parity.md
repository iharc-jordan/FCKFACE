# Combined SFace and GhostFaceNet development-crop probe — 2026-09-25

Desktop Chrome WebGL passed all four predeclared forward and input-gradient checks with **both models loaded in one worker**. This is an aligned-crop component check on `frll-024` and `frll-036` (`neutral_front`, development split), not a complete photo workflow or a privacy result. Root inspected all four 112×112 crops before the browser run.

The [native preparation](combined_crop_native.py) re-detected each decoded portrait with the calibrated YuNet max-side-640 path and required its mapped five-landmark row to match the earlier frozen detection. SFace used OpenCV `alignCrop`, 112×112 RGB float32 values 0–255, then OpenCV ONNX features and onnx2torch input gradients. Ghost used `author_align`, 112×112 RGB `(value − 127.5)/128`, the author H5 for forward comparison and the previously parity-checked float32 inference clone for gradients. Each model used its own fixed seeded random unit target in a cosine loss: SFace seed `20260128`, Ghost seed `20260512`. The Ghost clone removes training-only regularizers and is **not** the author's mixed-precision graph. Native SFace OpenCV versus onnx2torch raw maximum difference across cases was `6.68e-6`; native Ghost author versus clone unit cosine was at least `0.9999852392`.

The [worker](combined_crop_worker.js), [page](combined_crop_parity.html), and [allowlist loopback server](combined_crop_serve.py) used TensorFlow.js 4.22.0. The browser verified each crop PNG SHA-256, decoded RGB pixel SHA-256, and float32 input-tensor SHA-256 before running the converted SFace GraphModel and Ghost LayersModel in one WebGL worker. It did not independently hash every model shard response. The local server checked model JSON and reported local shard hashes. The predeclared limits were SFace raw max `1e-3`, unit cosine `0.99999`, gradient cosine `0.99`; Ghost clone raw max `1e-3`, author unit cosine `0.999`, author unit max difference `.02`, gradient cosine `.99`, with all outputs and gradients finite/nonzero.
